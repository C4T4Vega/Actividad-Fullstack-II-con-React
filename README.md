4. Instrucciones para ejecutar el proyecto.
   1. Verificar que Node.js esté instalado ejecutando el siguiente comando en `cmd`:
      ```cmd
      node -v
      ```
   2. Abrir el `cmd`, navegar hasta la carpeta raíz del proyecto utilizando el comando `cd`:
      ```cmd
      cd ruta\de\la\carpeta\del\proyecto
      ```
   3. Instalar las dependencias del proyecto ejecutando:
      ```cmd
      npm install
      ```
   4. Ejecutar el proyecto:
        ```cmd
        npm start
        ```
